Ширма мастера

Цифровая ширма для настольных ролевых игр D&D 5.5 (2024). Полностью офлайн: серверов нет, данные хранятся в браузере.

Что это и зачем

Рабочее место мастера вместо бумажной ширмы: персонажи, монстры, сессии, карта и бой — всё на одном экране, чтобы ничего не искать в книгах за столом. Данные сохраняются в браузере и не покидают ваш компьютер.

С чего начать

Меню «☰ → + Персонаж», затем «Бестиарий» для монстров. Создайте сессию во вкладке «Сессии» и добавьте карту во вкладке «Карта». Резервная копия — «Экспорт JSON».

Дополнительные возможности

  • Бестиарий — 596 монстров D&D 5e с поиском и добавлением на ширму.
  • База — заклинания и снаряжение PHB 2024.
  • Магазин — предметы и артефакты с ценами.
  • Эффекты — таблицы эффектов по типам монстров.
  • Таблицы — случайные таблицы для импровизации.
  • Кости — d4…d100 и свои грани, несколько бросков сразу.
  • Экспорт / Импорт — резервная копия всех данных.

Сохранение данных

Данные хранятся в браузере (localStorage и IndexedDB). Чтобы не потерять их при очистке истории, подключите папку на диске — в неё будет автоматически записываться файл shirma-backup.json при каждом изменении.

  1. Нажмите «Выбрать папку» и укажите любую папку (например, Документы/Ширма).
  2. Разрешите доступ, если браузер спросит.
  3. Файл обновляется сам. Для восстановления — «Меню ☰ → Импорт» и выберите этот файл.

Работает в Chrome и Edge (десктоп). В Safari/Firefox используйте «Экспорт JSON» и храните файл вручную.

Реакции и усиления монстров

Официальные свойства «Bloodied» из Monster Manual 2024 срабатывают при ХП ≤ 50%. Для «окровавлен» (≤ 10%) — домашние варианты.

Монстр / примерСостояниеУсиление / реакция
Кабан, гигантский кабан, квагготпотрёпанBloodied Fury: преимущество на броски атаки.
Берсерк, командир берсерковпотрёпанBloodied Frenzy: преимущество на атаки и спасброски.
Глиняный / мясной големпотрёпанBerserk: в начале хода бросает 1d6; на 6 — атакует ближайшее существо.
Чёрный пудинг, охра-желепотрёпанSplit: при 10+ ХП делится на два новых существа.
Гноллы, гигантская гиенапотрёпанRampage: после урона по уже раненому — движение на полскорости и атака.
Рои (крысы, летучие мыши, змеи и др.)потрёпанНаносит половинный урон (сокращается численность).
Любой монстр (домашнее)окровавленПоследний рывок: +1d6 урона и +10 фт скорости, но −2 КД.
Любой монстр (домашнее)окровавленОтчаяние: в начале хода спасбросок Мудрости DC 10, иначе пытается отступить.

Домашнее правило: эффекты и реакции не применяются автоматически — учитывайте их вручную.

Импорт персонажа / монстра из JSON
Поддерживаемые форматы

Можно импортировать один объект, массив или обёртки {blocks:[…]}, {characters:[…]}, {monsters:[…]}. Формат определяется по полям.

{
  "type": "character",
  "name": "Арин",
  "class": "Плут", "race": "Полурослик", "level": 3,
  "hp": 24, "ac": 15, "initiative": "+3",
  "abilities": { "str": 10, "dex": 16, "con": 12, "int": 13, "wis": 11, "cha": 14 },
  "attack": "+5",
  "resources": [{ "name": "Вдохновение", "cur": 1, "max": 1 }],
  "notes": "Любит тени и золото."
}
{
  "type": "monster",
  "name": "Гоблин",
  "cr": "1/4", "ac": 15, "hp": "7 (2d6)", "speed": "30 фт",
  "abilities": { "str": 8, "dex": 14, "con": 10, "int": 10, "wis": 8, "cha": 8 },
  "skills": "Скрытность +6", "senses": "Тёмное зрение 60 фт",
  "languages": "Общий, Гоблинский", "initiative": "+2",
  "actions": [ { "tag": "Действия", "name": "Скимитар", "text": "+4 к попаданию, 1d6+2 рубящего урона." } ]
}

Также принимается нативный блок ширмы: {"type":"pc"|"mob","title","stats":[6 чисел],"props":{…},"res":[…],"text","mdata":{…}}.
